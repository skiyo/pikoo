# 会话生命周期

[English](conversation-lifecycle.md) | **简体中文**

待机音频仅用于本地唤醒检测。唤醒后连接配置的 Live 服务，就绪后开启上传并简短问候。麦克风与播放不等待后台 HTTP 工作。

插话会清空播放队列并取消后台任务；互动分类还要求完整停止或纠正短语，因此“不要修改”这样的约束不应取消读取请求。迟到任务令牌直接丢弃。告别等待实际有声播放排空后断开语音，普通空闲 60 秒断开；明确结束清除短期上下文，空闲休眠保留。

静音关闭会话、清空播放并停采集。缺失配置不切换到其他运行时。鉴权失败须修改对应服务配置，限流采用退避，不快速循环重试。

告别会立即取消后台任务，同时允许告别语音排空；随后明确提出的新问题会取消告别计时，恢复正常互动。

## 状态说明

| 状态 | 音频与网络行为 | 用户操作 |
|---|---|---|
| 未配置 | 不建立语音会话 | USB 写入配置 |
| 待机 | 本地唤醒，不上传待机音频 | 完整唤醒词或短按 BOOT |
| 连接中 | TLS 与会话初始化 | 等问候，失败时查状态 |
| 活动会话 | 按事件采集、上传与播放 | 提问、追问、插话 |
| 告别 | 后端取消，告别音频排空 | 等待，或明确提出新问题 |
| 静音 | 关闭采集上传，清空队列 | 长按 BOOT 或 `unmute` |

取消同时包含后端结果标识失效和播放代次改变，防止旧网络结果或排队音频出现在新一轮中。取消不会撤回此前已完成提交的数据修改。

## 重连与错误

可恢复断线会尝试重新建立配置的会话，旧播放不能恢复。永久凭证或配置错误需要修正设置。短暂连接成功不代表音频连续；重复失败应查看脱敏计数器，分别测试“写入前取消”和“写入后断线”。
