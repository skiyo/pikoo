# 会话与休眠

[English](conversation-lifecycle.md) | **简体中文**

待机闭眼，只在本地检测唤醒。唤醒后连接并鉴权 Gateway、Live，就绪后睁眼并提交问候作为首轮。CONNECTING 不等于就绪，鉴权、额度和上游故障须可诊断。

通话期间持续上行麦克风，静音时停止。停止回答立即清空播放，不等于休眠；播放代次拒绝迟到旧音频。断线清空声音并退避重连，在有效范围内保留逻辑话题。

原生 Live 按 [Live 说明](openai-live.zh-CN.md)的 60 秒/15 秒语义空闲规则休眠。上下文确认的告别等待回答排空再关闭。待机不上传环境音；下次唤醒以保存文字创建新模型连接。设备结束、重启、标识过期和服务端文字保存是不同状态边界。
