# 常见问题

[English](faq.md) | **简体中文**

## 产品与硬件

### 整个 AI 模型都运行在 ESP32 上吗？
不是。ESP32 运行唤醒、会话状态、任务编排、工具和存储；语音与推理模型运行在配置的服务地址。Pikoo 是由设备管理任务、使用云端推理的硬件 Agent。

### 断网后还能使用吗？
本地唤醒、双眼、按键和已保存的数据属于设备能力；语音对话、推理与联网搜索需要访问服务。当前没有离线聊天模型作为回退。

### 需要自己部署 Pikoo 服务端吗？
不需要应用服务器，直接配置语音与推理服务即可。可选的通用网络传输配置见配置参考。

### 能烧到任意 ESP32 板上吗？
发布镜像只针对非触摸版 Waveshare DualEye，要求 16 MiB Flash 与 8 MiB PSRAM。其他板型需移植引脚、显示、编解码器、内存与分区，并重新构建和实机验证。

### 必须打印外壳吗？其他打印机可以用吗？
可以在外壳外完成电子部分配置。仓库提供 STL 与离线图文装配指南。更换打印机或材料后仍需检查配合尺寸；成功导入 STL 或选好参数不代表机械装配已经通过。

## 安装与服务

### 应该下载哪个文件？
安装使用 firmware ZIP；模型研究使用 model ZIP，其中包含推理权重、checkpoint 和元数据。GitHub 自动生成的源码 ZIP 包含已跟踪源码与权重，但不含构建出的板级镜像。单独 BIN 仅为应用分区镜像。

### 模型在哪？需要 Git LFS 吗？
位于 `models/hi-pikoo/`，文件为 `hi_pikoo.tflite` 与 `checkpoint.weights.h5`，不需要 Git LFS。checkpoint 用于训练；固件使用 TFLite 及匹配的唤醒策略。

### 只有聊天接口的服务商能提供语音吗？
当前 Live 适配器要求客户端委派、转写事件、PCM 和 Decisions，普通聊天接口不能替代。支持函数调用与工具结果消息的 HTTP 聊天接口可用于推理角色。

### 各服务能用不同密钥和供应商吗？
可以。每项服务独立设置协议、完整地址、密钥和模型，密钥不会跨服务继承。修改 URL 不会自动转换协议。

### 配置校验通过就说明 API 能用吗？
不是。校验在本地执行；实际还取决于模型权限、密钥有效性、协议实现与设备网络。401 通常与鉴权有关，429 通常与服务限流或额度有关。

### 搜索必须配置吗？可以读取任意网址吗？
搜索默认关闭。Tavily 配置同源提取地址后可启用 `read_webpage`。Responses 搜索提供搜索结果与引用，不提供任意网页提取。需要重定向或登录的页面不保证可读。

### 如何从英文切换中文？
把 `agent.language` 改为 `zh-CN`，执行 `device.py configure`。唤醒词仍为“Hi, Pikoo”。`configure.py --language zh-CN` 只改变设置助手提示语言，设备语言由配置字段控制。

### 密钥到期或更换 Wi-Fi 要重新编译吗？
不需要。修改完整的私有 JSON，通过 USB 更新即可。配置位于可更新的普通 NVS；正常配置和密钥轮换不涉及烧写 eFuse。

## 隐私、记忆与操作

### 为什么 USB 操作后显示 MIC OFF？
USB 工具维护前会主动静音，导出完成后仍保持静音。准备使用时执行 `device.py diagnose --port PORT --command unmute`，不需要为此重刷固件。

### 待机声音会上传吗？
待机唤醒检测在本地执行，活动会话才向配置的服务发送音频和任务上下文。静音会关闭采集和活动会话。服务商处理范围与物理访问边界见安全说明。

### 密钥是否加密？数据导出可以公开吗？
默认使用普通 NVS，没有启用安全启动和 Flash 加密，物理读取 Flash 可能暴露密钥。数据导出虽然排除凭证，仍含清单、记忆和上下文，因此仍是私有数据。

### 会自动记住所有听到的内容吗？
自动长期记忆学习关闭，只有明确的记忆指令用于保存事实。最近对话属于有界上下文，与长期记忆不同，也没有按声纹区分用户的功能。

### 可以保存多少内容？
购物、待办、记忆各最多 32 条，每条最多 512 个 UTF-8 字节；上下文最多 12 个片段，完整快照上限 24 KiB。UTF-8 字节数不等于汉字数。

### 为什么重复操作有时被去重，有时又执行了？
已保存的调用 ID 在有限回执窗口内用于防止重复执行，但两次独立请求可能产生不同 ID，即使文字相近也不保证去重。网络结果不确定时，应先读回数据再决定是否重试。

### 结束对话会清空清单吗？
不会。结束清除短期上下文，清单与显式记忆继续保留。`forget` 删除服务配置，不删除家庭数据。导入会替换快照，如需保留当前数据，应先导出。

## 可靠性、开发与许可

### 八小时模拟测试代表板上稳定运行八小时吗？
不代表。加速 PCM 回放验证合成负载下的软件行为；堆内存、Wi-Fi、I²S、AEC、供电和发热需实机测量。验证文档分别说明结果适用范围。

### 可以完全无声测试吗？
可以。原生测试使用固定 PCM 和内存接收器；离线双眼预览不调用模型、不打开音频设备。具体命令见开发指南。

### 固件包可以直接用于商业产品吗？
原创源码采用 Apache-2.0；唤醒权重及包含权重的固件另受非商业模型条款和第三方限制约束。源码许可不能直接授予模型商业使用权，应按预期用途核对随包条款。

### 怎样提交有效的问题反馈？
提供版本、板型、操作系统、操作步骤、预期与实际行为，以及脱敏状态和错误码；明确是模拟器还是板上结果。不要附带配置、密钥、录音或家庭数据快照。安全漏洞使用私密报告渠道。
