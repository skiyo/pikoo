# 家庭工具

[English](family-tools.md) | **简体中文**

DeepSeek 搜索使用 `DEEPSEEK_API_KEY`，校验 1–128 字符查询，默认 5 条、最多 8 条，8 秒超时，不循环重试。结果包含标题、链接、摘要和可用发布时间；鉴权、余额和限流失败如实返回。

公开网页阅读使用安全抓取器：阻断内网、重定向重新校验、限制 1MiB/12,000 字符及 8 秒总超时。网页内容只是资料，不能覆盖 Agent 指令。

家庭清单支持显式增删查改、清空，按家庭 owner 持久保存，与推断记忆分开。歧义操作需澄清。Terra 通过 Gateway 选择工具。MCP 是可扩展入口，不代表已接入日历、地图或智能家居。

工具调用 ID 持久预留以减少重放。崩溃后结果不明时先核查，不盲目重做副作用；不同调用 ID 的相同操作不承诺恰好一次。
