# 上下文与记忆

[English](context-memory.md) | **简体中文**

端侧 Agent 将家庭数据保存在设备 NVS，断线与休眠后恢复最多 12 条近期文字，不恢复旧音频或模型隐藏状态。流式回复按时间线组织；未知或背景输入不写入上下文。

购物、待办和显式长期记忆分别保存，每组最多 32 项、单项最多 512 UTF-8 字节。仅按用户明确要求写记忆，后台自动学习关闭。更正和删除直接修改真实存储并清除旧上下文。最近 32 个写调用 ID 与数据一起提交，重试不会重复写入。

快照上限为 24 KiB，使用双槽提交。USB 工具支持 export/import；凭证分区不参与家庭导出。保留迁移前原始备份，旧自动记忆中的矛盾内容须确认后再导入。单台共享设备不推断说话者身份。

旧 GCP 7 模式的服务端 Markdown、摘要和学习队列保留在兼容 Gateway 中，不属于端侧模式。
