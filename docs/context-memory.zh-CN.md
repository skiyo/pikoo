# 上下文与记忆

[English](context-memory.md) | **简体中文**

近期文字历史用于断线、休眠后的话题续接。设备保存最长 24 小时的逻辑会话标识；新建模型连接时，Gateway 注入有界文字和摘要，不恢复旧音频或模型内部隐藏状态。

长期家庭记忆独立保存在 Markdown。明确对 Pikoo 的互动可自动提取适合保存的事实，不需要每次说“记住”；Terra 通过持久学习队列整理摘要与记忆，背景聊天与对象不明的片段不进入自动学习。失败保留待处理状态，不偷偷换供应商。

纠错、删除操作修改真实存储并使旧摘要失效，避免再次引入删除信息。购物/待办属于独立显式工具数据，不是推断事实。同一家庭 owner 共享；需要知道是谁时询问，不根据声音猜身份。服务端注入 Asia/Shanghai 的当前时间。

完整备份所有私密状态。长对话和真实家庭回忆质量仍受场景影响，存储测试通过不代表永不遗忘。
