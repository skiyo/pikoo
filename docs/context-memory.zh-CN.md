# 上下文与记忆

[English](context-memory.md) | **简体中文**

购物清单、待办、显式记忆和近期对话分别保存。清单与记忆每组最多 32 项、每项最多 512 UTF-8 字节；上下文最多 12 个文本片段；包含写入回执的快照总计不超过 24 KiB。

长期记忆仅按用户明确指令修改，自动学习关闭。更正和删除清除旧上下文。NVS 双槽提交在写入失败时保留前一快照。USB 导入导出只移动家庭状态，不包含服务凭证。明确结束会话清除短期上下文，普通空闲休眠保留。

## 数据归属与备份

## 区分不同存储

| 数据 | 写入来源 | 生命周期 |
|---|---|---|
| 购物/待办 | 明确工具操作 | 持久保存直到修改或替换 |
| 显式记忆 | 明确请求的记忆工具 | 保存直到纠正或删除 |
| 会话上下文 | 有界交互处理 | 明确结束、相应纠正操作时清理 |
| 写入回执 | 成功的数据修改 | 有限去重窗口 |
| 服务配置 | USB 配置 | 独立于家庭快照更新 |

完整快照共用容量预算，因此各集合都允许一定条数，并不意味着能同时填满所有最大长度条目。容量不足必须如实报错，不能宣称保存成功。

## 持久化的边界

双槽用于抵御不完整的软件提交，不替代私有备份，也不保证覆盖所有 Flash 或断电故障。导入或清空前先导出。完整 Flash 备份含凭证和数据；家庭导出不含凭证，但仍是私有内容。导入为替换而非合并，命令与重启要求见 [USB 维护](firmware.zh-CN.md)。

当前只提供设备共享存储，不提供按说话人授权、自动同步、跨设备冲突解决或环境对话自动学习。
