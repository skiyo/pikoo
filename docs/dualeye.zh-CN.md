# 双眼显示

[English](dualeye.md) | **简体中文**

两块 240 × 240 圆屏共用 `pikoo_eyes` C++ 绘制器，ESP 与桌面使用同一姿态和像素绘制代码。设备生命周期与输出电平驱动表情；纯预览姿态不改变 Agent 状态。

运行[离线双眼预览](getting-started.zh-CN.md)，不采音、不连接模型。慢浏览器只接收最新姿态，避免无界帧积压。硬件帧率与传输耗时须在目标板测量。

## 启动预览

```sh
(cd firmware/simulator && npm ci --ignore-scripts)
bash tools/start-dualeye.sh
```

打开 `http://127.0.0.1:8793/dualeye`，通过状态和表情控件比较待机、倾听、思考与说话效果。界面默认英文，可切换中文。Ctrl+C 或 `bash tools/stop-dualeye.sh` 停止。预览只在本地运行，不使用麦克风、扬声器或模型密钥。

## 修改表情

将姿态和状态映射与服务商消息分离。装饰性表情不能证明网络就绪或工具保存成功。检查双屏、圆形边界裁切和不同强度间的过渡，继续使用共享渲染器避免平台偏差。

实机同时运行音频时，检查亮度、方向和 SPI 时序。通过 USB 的 `rotate 90` / `rotate 270` 设置方向，重启验证持久化。浏览器流畅不能证明面板帧率，需单独采集板上时序、堆和队列数据。
