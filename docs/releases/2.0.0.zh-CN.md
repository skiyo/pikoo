# Pikoo 2.0.0

[English](2.0.0.md) | **简体中文**

基于 ESP32-S3 的硬件 AI Agent，在设备管理会话、工具、清单和显式记忆，独立配置语音、推理与搜索服务。

## 功能

- 默认英文，`agent.language: "zh-CN"` 切换中文。
- Live 客户端委派、Responses/Chat Completions 推理、可选 Tavily/Responses 搜索，无需 Pikoo 应用服务器。
- 本地“Hi, Pikoo”唤醒、插话、静音、告别休眠、重连与双眼表情。
- USB 配置与数据备份；有界队列、取消、持久化写入去重。
- JSON 优先使用 PSRAM，任务范围内 HTTP 复用减少重复 TLS 建连。

## 下载

- **固件 ZIP：**源码、安装工具、匹配板级镜像、依赖声明和校验和；首次安装使用此包。
- **模型 ZIP：**推理权重、训练 checkpoint、策略、发布记录、条款和来源。
- **应用 BIN：**只包含应用分区，需要匹配分区/模型布局；常规更新使用 ZIP 内安装器保留数据。
- **清单与 SHA256SUMS：**用于核对构建身份和下载完整性。

自行填写私有 Wi-Fi 与服务配置，包内不含密钥、NVS 或用户数据。原创源码采用 Apache-2.0，模型和包含模型的固件保留非商业条款与第三方限制。模型包包含维护者确认的发布记录和来源署名，不授予商业模型许可或源录音分发权。
