# Pikoo 2.0.0

An ESP32-S3 hardware AI Agent with device-local sessions, tools, lists, explicit
memory and configurable voice, reasoning and search services.

- English by default; configure `agent.language: "zh-CN"` for Chinese.
- Live client delegation, Responses/Chat Completions reasoning and optional
  Tavily/Responses search. No Pikoo application server is required.
- Local “Hi, Pikoo” wake, interruption, mute, farewell sleep, reconnect and
  expressive dual displays.
- USB configuration and backup; bounded queues, cancellation and persistent
  write deduplication. JSON prefers PSRAM and task-scoped HTTP reuse reduces
  repeated TLS setup.

## Downloads

- **Firmware ZIP:** source, installation tools, matching board images,
  dependency notices and checksums. Use this for first installation.
- **Model ZIP:** inference weights, training checkpoint, model policy, permission
  record, terms and attribution.
- **Application BIN:** application partition only; not a complete Flash image.
  Use only with the matching partition/model layout. For updates, use the USB
  installer from the ZIP to preserve device data.
- Verify `SHA256SUMS` and `release-manifest.json`. Supply your own private Wi-Fi
  and service configuration; no keys, NVS or user data are included.

Original source is Apache-2.0. Wake weights and firmware containing them retain

The project maintainer confirms model publication permission; the permission
