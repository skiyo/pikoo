# 公开仓库质量

[English](public-audit.md) | **简体中文**

公开文档描述产品、接口和可复现工作流程，示例使用占位值。私人部署细节、私人地址、凭证、设备备份、录音和用户快照不进入源码或发布包。

## 技术审查

在仓库根目录运行 `python tools/check-public-repo.py`，检查跟踪文件、示例凭证占位、本地 Markdown 链接及模型校验和。CI 另行运行脱敏 Gitleaks 历史扫描。处理发现时不打印匹配密钥。通过仅代表已实现规则没有发现问题，不保证识别所有私有内容。

发布前审查实际跟踪差异与归档列表，确认中英文导航和命令一致，下载指向正确 Release，示例格式有效。构建产物不提交到源码。完整 Flash 备份即使有助于复现设备故障，也仍属于私有内容。

## 许可边界

原创源码和文档使用 Apache-2.0，模型权重另有非商业条款，依赖保留各自许可。参阅[第三方来源](../THIRD_PARTY.zh-CN.md)、[模型条款](../models/hi-pikoo/LICENSE.md)与[发布记录](../models/hi-pikoo/PERMISSION.md)，再分发时保留这些资料。

`distribution-status.json` 将发布元数据与模型哈希绑定，打包前验证记录和文件完整性。这不授予新的商业许可或原始训练录音分发权。非商业模型条款不属于 OSI 开源许可。

## 审查清单

- 源码和示例不含个人凭证或数据。
- 宣称能力均对应已实现适配器与工具。
- 默认英文，中文说明与实际配置行为一致。
- 链接、产物名称和校验和对应实际文件。
- 软件与实机结果标明环境及限制。
- 相关资产附带许可、来源署名和模型条款。
