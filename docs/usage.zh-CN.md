# 使用 Pikoo

[English](usage.md) | **简体中文**

## 唤醒、说话与停止

配置有效且设备未静音时，说出完整的 **“Hi, Pikoo”**。唤醒检测在本地执行，听到问候后再提问。网络与服务商响应速度会影响就绪时间。默认对话语言是英文，设置 `agent.language: "zh-CN"` 即可使用中文，唤醒词不变。

| 操作 | 效果 |
|---|---|
| 短按 BOOT | 待机时唤醒；回答中停止当前回答 |
| 双击 BOOT | 结束对话并清除短期上下文 |
| 长按 BOOT | 切换麦克风静音 |
| RESET | 重启，保留已保存的配置与数据 |
| 语音插话 | 识别后取消当前任务和排队语音 |
| 说再见 | 播完告别语后回到本地待机 |

自然语言识别可能出错。需要明确停止时，使用 BOOT 或 USB 的 `stop`、`end` 命令。静音会清空播放并关闭会话。无活动会话在 60 秒后关闭；明确结束会清除短期上下文，普通空闲休眠保留有界上下文。

## 尝试本地工具

- “购物清单加上苹果。”随后说“读一下购物清单，不要修改”。
- “待办加上给植物浇水。”随后说“删除待办中的给植物浇水”。
- “请明确记住：我喜欢简短的回答。”随后询问“我让你记住了什么？”
- “把购物清单里的苹果替换为青苹果。”
- 启用搜索后说“联网搜索一下……”。

以工具结果为准，不要仅凭一句泛化回答判断写入成功。本地提交成功后，即使网络失败也不会自动撤回；重复请求前先读回清单。清空整组内容需要确认。设备数据由使用者共享，没有声纹身份或独立用户账户。

## 音量与屏幕方向

新设备默认 -24 dB。根据实际扬声器从低音量开始调整：

```sh
python tools/device.py diagnose --port PORT --command 'volume -24'
python tools/device.py diagnose --port PORT --command 'rotate 90'
```

音量支持 -50 到 0 的整数 dB；0 表示最高设置，不是静音。方向命令支持 `rotate 90`、`rotate 270`。同分区升级会保留这些设置。调低扬声器音量不会关闭麦克风，需要保护麦克风输入时请使用静音。

## 使用边界

对话依赖网络模型服务，本地唤醒和数据存储不代表 ESP 内运行了离线大语言模型。搜索可选且取决于适配器；配置 Tavily 提取地址后才提供网页读取。活动会话中的语音和文本由对应服务商处理。长期记忆应明确提出，重要清单建议通过 USB 备份。
