# 使用 Pikoo

[English](usage.md) | **简体中文**

## 唤醒、说话与停止

配置有效且设备未静音时，说出完整的 **“Hi, Pikoo”**。唤醒检测在本地执行，听到问候后再提问。网络与服务商响应速度会影响就绪时间。默认对话语言是英文，设置 `agent.language: "zh-CN"` 即可使用中文，唤醒词不变。

| 操作 | 效果 |
|---|---|
| 短按 BOOT | 待机时唤醒；回答中停止当前回答 |
| 双击 BOOT | 结束对话并清除短期上下文 |
| 长按 BOOT | 切换麦克风静音 |
| RESET | 重启，保留已保存的配置与数据 |
| 语音插话 | 识别后取消当前任务和排队语音 |
| 说再见 | 播完告别语后回到本地待机 |

自然语言识别可能出错。需要明确停止时，使用 BOOT 或 USB 的 `stop`、`end` 命令。静音会清空播放并关闭会话。无活动会话在 60 秒后关闭；明确结束会清除短期上下文，普通空闲休眠保留有界上下文。

## 尝试本地工具

- “购物清单加上苹果。”随后说“读一下购物清单，不要修改”。
- “待办加上给植物浇水。”随后说“删除待办中的给植物浇水”。
- “请明确记住：我喜欢简短的回答。”随后询问“我让你记住了什么？”
- “把购物清单里的苹果替换为青苹果。”
- 启用搜索后说“联网搜索一下……”。

以工具结果为准，不要仅凭一句泛化回答判断写入成功。本地提交成功后，即使网络失败也不会自动撤回；重复请求前先读回清单。清空整组内容需要确认。设备数据由使用者共享，没有声纹身份或独立用户账户。

## 控制声音与双眼

唤醒后可直接提出以下指令。音量和亮度只在明确要求时调整并保存，微笑、眨眼和视线是临时动作。

| 指令 | 实际行为 |
|---|---|
| “声音大一点／小一点” | 当前芯片增益增加／减少 3 dB，到达边界时如实反馈 |
| “音量调到一半” | 控制档位设为 50%，对应 −25 dB 增益 |
| “眼睛亮一点／暗一点” | 双眼背光同步增加／减少 10 个百分点 |
| “眼睛亮度调到零” | 关闭背光，麦克风和会话继续按原状态运行 |
| “笑一笑／好奇一点／困一点” | 对应表情保持 3 秒，再恢复会话表情 |
| “眨一下眼／眨左眼／眨右眼” | 执行一次双眼或单眼眨眼，约 350 ms |
| “看看左边／右边／前面” | 改变屏幕视线，保持 2 秒后恢复 |
| “别说了” | 停止播放并取消当前回复，仍可继续交流 |
| “休息吧” | 结束会话、闭眼，回到本地唤醒待机 |
| “关闭麦克风” | 停止采集；通过长按 BOOT 或 USB `unmute` 恢复 |

左右按人面对屏幕时的视角定义。可以明确指定表情或视线的时长，最多 10 秒；新的同类动作替换旧动作。显式动作优先于自然表情，但麦克风关闭、连接和错误状态仍优先显示。“笑一笑”只改变眼睛；需要笑声时说“笑出声”。双眼是显示器，视线变化不代表看到了物体。

芯片增益范围为 −50～0 dB，0 dB 是最高设置，不是静音。音量百分比是控制档位，不是实际声压比例或耳边分贝。新设备默认 −24 dB，升级会保留已有设置。背光范围 0～100%；关灯后仍可唤醒并说“把眼睛亮度调到百分之百”。调低音量或亮度都不会关闭麦克风。

## USB 设置与恢复

语音服务不可用时，可通过 USB 查询实际状态或恢复亮度：

```sh
python tools/body.py --port PORT body_get_state
python tools/body.py --port PORT body_set_audio '{"gain_db":-24}'
python tools/body.py --port PORT body_set_display '{"percent":100}'
python tools/device.py diagnose --port PORT --command 'unmute'
python tools/device.py diagnose --port PORT --command 'rotate 90'
```

方向设置支持 `rotate 90`、`rotate 270`；同分区升级保留音量、亮度和安装方向。屏幕旋转用于安装校准，日常“看左／右”只移动视线。USB 工具与语音共用身体执行器，接口和回执含义见[工具契约](family-tools.zh-CN.md)。

## 使用边界

对话依赖网络模型服务，本地唤醒和数据存储不代表 ESP 内运行了离线大语言模型。搜索可选且取决于适配器；配置 Tavily 提取地址后才提供网页读取。活动会话中的语音和文本由对应服务商处理。长期记忆应明确提出，重要清单建议通过 USB 备份。
