# 播放声音误唤醒排查

[English](wake-playback-negatives.md) | 简体中文

本轮处理普通讲话、电视和短视频播放造成的误唤醒。继续要求完整的
**Hi piku / Hi piko**，保留三次概率平均及 0.90 阈值。部署中的网络结构
不变；另设离线对照将分类层由 32 扩到 64 单元，训练前先验证原浮点函数不变。
中文通话、音色、音量、服务器网络和家庭记忆不在此次修改范围内。

## 数据与隔离

| 来源 | 用途 | 条款与限制 |
| --- | --- | --- |
| [LibriSpeech](https://www.openslr.org/12/) `train.100` | 真实成人英语普通讲话负样本 | CC BY 4.0；在模型评分前按说话人划分 TRAIN/DEV。朗读音频不等于真实电视对话。 |
| 已获授权的 [ChildMandarin](https://huggingface.co/datasets/BAAI/ChildMandarin) | 真实儿童普通话负样本 | 保留官方 TRAIN/DEV；受非商业研究条款约束。不重新下载整套数据，不采集家庭录音。录音和衍生模型只保留本机。 |
| [ESC-50](https://github.com/karolpiczak/ESC-50)，提交 `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6` | 环境声与非语言人声 | 50 类，TRAIN 300 段、DEV 100 段；按原始录音分组。ESC-10 保留 CC BY，其余选中片段保留 CC BY-NC。开发阶段不读取第 5 折音频。 |
| 同集合连续讲话播放列表 | 检查跨片段状态累积 | 普通录音之间加 150ms 间隔；所有父录音维持原集合。这是构造的播放挑战，不冒充自然家庭聊天。 |

通过命令行 HTTP 有界下载小部分数据，不使用浏览器下载或整套数 GB 归档。
请求失败就记录失败，不补造样本。本轮语料不需要付费生成。

已有保护摘要继续排除家庭录音、试听音和已经消耗的 TEST。DEV 只参与
模型选择；只有 TRAIN 的分数可以改变困难负样本权重。包含已知目标词或
同音写法的普通讲话排除。提取特征前检查说话人、原始录音、播放列表父项、
波形摘要和本机路径，禁止跨集合泄漏。

## 复现流程

使用固定的 `training/requirements.txt` 环境、FFmpeg 和固定干净版本的
microWakeWord。所有输出放在公开仓库外。

1. `training/wake_playback_negatives.py collect --output PRIVATE_RUN` 下载并
   转换环境声小样本。
2. `collect-speech` 复用已授权儿童语料并获取英语录音；`playlists` 构造
   连续播放挑战。
3. `score` 对原始完整录音持续提取特征并保留状态，使用固定原生 Micro
   内核回放；三次重置回放必须一致，再按当前设备固定规则判定。
4. `training/wake_negative_finetune.py` 要求原模型检查点、已审核 TRAIN/DEV
   特征缓存、保护摘要和负样本基线。每轮两个固定随机种子、有限训练轮数；
   重叠窗口覆盖负样本全文及末尾。
   `--warm-frontend` 另外使用完整 TRAIN 录音持续提取的特征窗口，保留音频
   前端的噪声／PCAN 状态。`--head-units 64` 是明确记录的容量对照，不自动升级设备。
5. INT8 转换后检查原有完整唤醒 DEV 和新增负样本 DEV。进入候选的条件是：
   各原有正样本组命中数不下降，原负样本与提前触发不恶化，新增误触发片段
   至少下降 80%。

各命令的 `--help` 列出明确输入路径。实验输出目录不能悄悄复用为新实验。
失败候选与来源记录保留；完全不唤醒的模型不能算解决问题。

## 结果和烧录边界

分别报告误触发片段数和带明确 3 秒冷却规则的事件数。短时回放不能当作
8 小时误唤醒验收。连续播放列表与父录音有重叠，只列为额外挑战时长，不
重复计算成独立语料小时数。

批量与流式一致、原生内核重置一致、模型足够小、DEV 改善，都不能代替
ESP32 或家庭实测。选中候选仍须冻结后独立检查，再做可恢复的实机测试。
工具不自动烧录或修改设备。实际结果记录在 `docs/reports/` 的带日期 JSON 中。

`wake_negative_recalibrate.py` 对照原始和按来源分层的 TRAIN 量化校准集，
不更新浮点权重、不改变阈值；用原生 Micro 检查原有完整 DEV，再回放新增完整语料。
校准不使用 DEV 或 TEST 波形。

原创代码采用 Apache-2.0；录音与衍生权重保留各自条款，不进入公开 Git。

[完整对照记录](reports/wake-playback-negatives-2026-11-02.json)：整理 1,455 段原始
负样本，包括复用的 751 段儿童普通话、新下载的 304 段成人英语和 400 段环境声；
另有 12 份衍生播放列表。完成 12 个训练候选、2 组量化校准对照。本轮 API 费用
为 0 美元。没有候选同时通过替换条件，未修改设备。

| 模型 | 原有合成正样本 DEV 命中 | 新负样本 DEV 误触发片段 |
| --- | --- | --- |
| 当前已部署基线 | 86/92 | 6/261 |
| 保住原 DEV 各组命中与错误数的最优版本 | 86/92 | 4/261 |
| 更强抑制的一个例子：连续前端、种子 43 | 85/92 | 1/261 |

新增负样本 DEV 包括 257 段原音和 4 份衍生播放列表，挑战时长约 27.5 分钟，
其中包含与父录音重叠的内容。这是反复用于选模的 DEV，不是独立测试或 8 小时
验收。来源文献：Piczak (2015)，ESC-50；Panayotov 等 (2015)，LibriSpeech；
[Zhou 等 (2024)，ChildMandarin](https://arxiv.org/abs/2409.18584)。

## 继续迭代：按原生 INT8 选择检查点

`training/wake_int8_iterate.py` 现在每个训练轮次都导出 INT8，用固定原生 Micro
后端检查原有完整 144 条 DEV 和新增 261 份负样本挑战，每段均做 3 次重置一致性
回放。检查点不再只按浮点成绩选择。

正式冻结条件继续要求：原有各组召回至少 90%，命中数不低于当前基线，原有误触发
和提前触发为零，新增负样本 DEV 误触发也为零。“最多 1 段误触发”仍只是中间阶段
门槛。本次继续迭代尚未安装新候选。

只有输入、保护摘要、准备逻辑及依赖、数组摘要一致才复用 TRAIN/DEV 缓存。原音、
已消耗 TEST 和历史失败不改写。首次完整过关后冻结候选，再打开全新独立 TEST。

本轮对照只依据 TRAIN 统计的事件权重，以及成人／童声风格、口音和读音的 6 个
正样本组。可通过 JSON 配置复用已审核检查点，或复用仅用公开中国儿童 TRAIN
训练过的音素编码器；编码器的音素错误率不等于唤醒验收成绩。不重新下载大模型，
不训练家庭录音。参数见命令的 `--help`。

另用 [GPT-Transcribe](https://developers.openai.com/api/docs/models/gpt-transcribe)
对原有全部 144 条虚构合成 DEV 做独立盲审，未上传真实儿童语料或家庭录音。
接口计费音频时长为 263 秒，按官方价格估算约 $0.019725，仍在原 $2 语料预算内，
尚非账单对账结果。转写冲突不自动删音或改标签；人工核对合成内容与家庭真人唤醒
验收分别记录。

### 仅训练时使用短句类别监督

下一组有限对照在训练时增加 6 类辅助输出：普通讲话、完整唤醒词、T 开头名字、
单独 Hi、单独名字、缺最后音节。部署时仍导出原来的**单一 sigmoid 唤醒概率**，
不导出辅助分类层，也不改变设备触发规则。这与直接部署短句 softmax 分类不同。

`training/wake_train_events.py` 先核对原始准备代码快照，再逐条重放原有 TRAIN。
特征、标签、权重、形状和数据类型必须与原缓存逐字节一致，才能使用恢复的事件
元数据。合成近似词按实际语音尾部和原有变速、补白确定辅助事件时间，不能把文件
静音尾巴当作音素结束。二元标签及原音不变；该步骤不读取 DEV 原音、TEST 或
家庭录音。

通过 `--phrase-events` 传入核对后的元数据，配置中的 `auxiliary_phrase_weight`
只允许 0、0.2 或 0.5。元数据必须对应原缓存和当前保护摘要。完整原生 INT8 DEV
门槛不变，辅助分类代码完成不代表召回或真实误唤醒已经改善。

### 保守 TRAIN 隔离对照（2026-11-03）

独立盲审覆盖全部 407 条合成 TRAIN 原音。现有保守内容规则与其中 323 条转写
一致；另将 84 条不确定原音及全部增强后代共 762 个样本隔离，单独训练对照。
ASR 冲突**不等于已确认错音**：口音、陌生名字拼写和 ASR 自身失败都可能排除
实际正确的目标。原音、原标签和完整 DEV 均不删改。

`--train-admission` 要求完整划分原有合成 TRAIN 摘要；不确定样本不进入训练、
量化校准或组别权重统计。普通公开负样本保留，辅助事件元数据使用同一原始索引
筛选。本次对照保留 10,150 个 TRAIN 样本，两个时间窗口、每种两个随机种子，
每次最多 20 轮。尚无可部署的合格候选。
