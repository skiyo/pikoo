# Agent 能力

[English](agent.md) | **简体中文**

本地 Agent 管理任务，不把设备事件转交给应用服务器。Live 提供语音与互动信号；独立 LLM 根据有界、已分类的上下文推理并选择已注册工具。模型响应不能直接操作存储。

| 能力 | 设备行为 |
|---|---|
| 唤醒与隐私 | 完整本地唤醒词；待机不上行；静音关闭采集 |
| 对话 | 问候、连续追问上下文、插话取消、60 秒空闲休眠与告别播放排空 |
| 本地动作 | 购物清单、待办和用户明确要求的记忆修改 |
| 检索 | 可选搜索、来源链接；有对应适配器才开放网页提取 |
| 恢复 | 断线重连不复播旧音频；USB 配置与快照传输 |

工具声明名称、说明和 JSON 参数结构，由执行器校验参数并应用有界操作。写入调用 ID 和状态一起提交，清空须确认，歧义修改应先询问。已保存的修改不会因后续网络失败而回滚。去重针对已保存的调用 ID，不承诺不同 ID 的语义相同请求恰好执行一次。

设备面向家庭共享，不推断说话者身份，不自动后台学习、不跨设备同步，也未内置智能家居平台。联网对话需要模型服务。
