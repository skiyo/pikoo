# 验证与发布

[English](release.md) | **简体中文**

Pikoo 2.0.0 已通过下列软件检查及配置 HTTPS CONNECT 的实机场景。当前网络未建立 OpenAI 直连会话，直连板上并发资源仍未验证。本轮不新增标签，也不替换已有二进制发布资产。

## 实机证据

最终 ESP32-S3 镜像为 2,740,848 字节，静态 DIRAM 为 168,907 字节，已关闭 Agent 事件跟踪。刷写前将 16 MiB Flash 分 64 块备份并校验，只写应用分区，各次刷写均核对配置和数据分区。合成测试结束后，恢复原始家庭快照并重新导出一致；音量和方向设置保留，全程无需人工拔插 USB。

| 场景 | 观察结果 |
|---|---|
| 本地唤醒 | 最终镜像首次播放固定完整英文短语即唤醒，得分 0.960。仅为工程样本，不代表召回率验收。 |
| 清单与显式记忆 | 真实工具写入和读回通过，软件重启后整份快照一致。 |
| 搜索 | Live 与独立 Responses 推理／搜索并存，三轮均返回 HTTP 200；独立搜索调用 5,166 ms，满足 8,000 ms 期限。 |
| 鉴权 | 仅换成无效 LLM 密钥时返回 401，语音链路仍可用，清单与记忆不变；恢复密钥、重启后可通过工具读回记忆。 |
| 插话 | 故事实际播放时要求停止，随后输出安静；新的算术问题回答正确。 |
| 迟到结果 | 后端请求进行中打断，取消结果被丢弃，没有记忆写入；后续工具请求正常完成。 |
| 隐私 | 告别后回本地待机；静音十秒未增加采集或上传样本。 |
| 最终镜像稳定性 | 120 秒语音流窗口及故障场景合计 188.89 秒：无意外重连、队列溢出、I²S／帧发送错误或观察到的播放供给间隔。 |

最终镜像该轮运行的内部堆低水位为 **27,308 字节**，采样到的最小“最大连续块”为 **23,552 字节**，后台栈余量 **6,256 字节**。播放队列峰值 14,400 样本，即 16 kHz 下的 900 ms。注入 1.5 秒发送暂停后，观察到上行队列峰值 46／80 帧，随后排空，无溢出。这些是板上指标，与桌面 RSS 分开。另记录四次最终镜像 TLS 观察值，其分位数仅供工程参考，不是 100 次板上连接基准。

## 软件检查

- 原生播放／会话／双眼、17 项服务行为 ASan/UBSan、66 项 Python 工具、4 项双眼预览、19 项规划检查通过。
- 使用独立假凭证的 100 轮回环 TLS／CONNECT／服务组合通过，包含证书、鉴权、限流、断线及两种 LLM／两种搜索协议。
- 八小时等量 PCM 与 28,800 次后台任务在桌面加速回放中完成，虚拟欠载为零；不是八小时墙钟实机运行。精确耗时、内存单位和范围见[脱敏验证数据](verification.json)。
- 可选训练套件单独运行：206 项中通过 138 项，需要额外运行时或上游检出的 68 项跳过，不计入默认运行时检查。

## 验收边界

实际账号覆盖 OpenAI Live 与 Responses；其他适配器使用假服务回归。直连板上并发、真实断电、主观听感、装壳 AEC、真人／儿童／家庭唤醒及长期家庭试用仍需另验，不能由合成语音、I²S 写入成功或桌面回放替代。本次未录制电脑麦克风；自动证据来自设备转写、输出时序和持久化读回。

## 打包与权限

[模型分发权限](../models/hi-pikoo/distribution-status.json)待确认期间，公开模型与固件打包仍被阻止。实机通过不代表取得上游授权，见[公开审核](public-audit.zh-CN.md)。许可补齐后，`tools/package-release.py` 会检查模型策略与构建匹配，并附上实际依赖许可、来源和校验和。禁止包含 NVS、配置、密钥、家庭数据或录音。
