# 验证与发布

[English](release.md) | **简体中文**

Pikoo 2.0.0 工程检查覆盖共享 C++ 核心与 ESP32-S3 板卡，测量值和边界见[结构化结果](verification.json)。

## 验证范围

- 原生播放、会话与双眼；18 项服务行为 ASan/UBSan；67 项 Python 工具、5 项预览与 19 项规划检查。
- 100 轮独立假凭证的本地 TLS／服务故障组合，覆盖两种 LLM 和两种搜索协议。
- 桌面加速完成八小时等量 PCM 与 28,800 次后台任务，虚拟欠载为零；不是八小时墙钟实机运行。
- 板上外放唤醒、语音、清单与显式记忆工具写入、重启读回、搜索、插话、取消、鉴权失败与恢复、告别和静音。
- 最终板上负载包含 120 秒语音流与故障场景，无意外重连、队列溢出、I²S／帧发送错误或观察到的播放供给间隔。内部堆低水位 27,308 字节；采样到的最小最大连续块 23,552 字节；后台栈余量 6,256 字节。
- 应用镜像 2,740,848 字节，静态 DIRAM 168,907 字节；构建标识和 SHA-256 见结果文件。源码或构建选项变化后需重新构建和验证。

合成语音不能证明家庭／儿童唤醒率、主观听感、装壳 AEC、真实断电恢复或长期可靠性。不同服务和网络传输组合需分别验收；可选训练运行时单独测试。

## 发布检查

校验配置，运行 `tools/check.sh`，交叉编译目标板，检查镜像与分区范围，完成实机验收并核对许可和校验和。发布包不能包含 NVS、凭证、录音或用户数据。

本次按[维护者确认的发布许可](../models/hi-pikoo/PERMISSION.md)及现有非商业模型条款发布。

英文默认和双语停止指令已通过原生测试与交叉编译；板上指标绑定已测镜像，语言默认修改不代表重新认证声学效果。
