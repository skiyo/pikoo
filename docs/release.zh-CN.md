# 1.0.0 发布检查

[English](release.md) | **简体中文**

## 发布内容

当前双眼固件与源码、模拟器、原生 Live/Terra Gateway、唤醒推理权重及训练检查点、原创外壳 STL、双语安装/开发文档和第三方许可。[下载](https://github.com/skiyo/pikoo/releases/tag/v1.0.0)。

- `hi-pikoo-firmware-1.0.0.zip`：源码、引导程序、分区、应用、SR 资源、USB 工具及依赖许可。不含 NVS 和凭证。
- `hi-pikoo-model-1.0.0.zip`：TFLite、检查点、结构配置、冻结策略、模型卡、条款与来源。不含训练音频。
- `release-manifest.json`、`SHA256SUMS`：版本、模型/策略/固件标识与包摘要。

## 本次验证

原生 C++ 音频、会话、播放与双眼检查通过，包括确定性画面、边缘、过渡和迟到音频。模拟器、服务端与 JavaScript 数据工具回归通过；Python USB/工具 56 项通过，训练单元 206 项运行、15 项因可选运行时跳过，跳过不作为验收成绩。

独立干净源码目录成功安装依赖并启动离线模拟器，没有 `.env.local`、模型、私密配置或 API 调用。ESP-IDF 5.5.5 在独立源码/构建目录生成 1.0.0，绑定公开模型及策略摘要，没有写 USB。训练检查点按公开配置成功恢复，网络参数 55,329。

本地文档链接、包内摘要和敏感文件在发布前核对。打包工具及命令见[英文说明](release.md)；只收 Git 索引内的预期源码，权重和固件输入留在仓库外。解压后再核对包内 `SHA256SUMS`。

## 实测边界与恢复

此次发布不认证正式家庭召回、真实儿童准确率、8 小时误唤醒、72 小时稳定性或通用 AEC 效果。固件已编译，本次没有重新刷写家中设备。推理耗时与来源见[模型卡](../models/hi-pikoo/MODEL_CARD.zh-CN.md)。

回滚应用前核对同一分区布局并保留 NVS；完整原厂恢复需该板私密 16MiB 备份。服务端回滚保留新产生的家庭记忆、清单和学习状态；官网回滚旧 Worker 版本，不修改数据资源。
