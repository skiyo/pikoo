# 2.0.0 发布检查

[English](release.md) | **简体中文**

项目 VERSION、固件版本及兼容服务端包版本统一为 2.0.0。端侧 C++ Agent 通过 Mihomo 连接 OpenAI，本机保存可替换凭证、清单、显式记忆与有限文字上下文。旧 Gateway 保留回滚能力。

当前状态：正式固件已构建并刷入；最后真人清单查询确认尚待完成，主干未合并。

## 已完成验证

- 模拟器与服务端 93 项、Python USB/配置工具 60 项通过。
- C++ 核心 ASan/UBSan、8 小时等量 PCM 加速回放通过；欠载为 0。较早的 30 分钟及 8 小时墙钟测试来自初版流式核心。
- 实际 Mihomo 与本机假 OpenAI 完成 100 次双 TLS、CONNECT、WebSocket 和证书/鉴权/重连故障测试。
- 实机完成 100 次 USB 重开、20 次控制线复位、凭证覆盖恢复、16/24 kHz 语音，以及数据写入与重启读回。
- 插话清队列、停止后无旧音频复播与后续问答通过；分片转写、误停止及迟到工具结果有原生回归。

测量数值、可复跑命令、硬件边界和当前验收状态见[本地 Agent](local-agent.zh-CN.md)与[脱敏 JSON](verification-2.0.0.json)。真实儿童召回、所有家庭声学环境和 24 小时实机稳定性未认证。

## 构建与打包

使用[固件说明](firmware.zh-CN.md)构建，详细 Agent 追踪关闭。原公开 1.0.0 模型包中的权重保持兼容，必须校验与冻结策略的匹配。`tools/package-release.py` 可打包源码、Flash 镜像、USB 工具、模型及许可；输入模型与检查点保存在仓库外。打包器拒绝 NVS 与录音，生成 SHA256SUMS 与来源清单。

完整 Flash 备份、Wi-Fi、OpenAI 密钥、代理凭证、家庭资料及测试录音不进入 Git 或发布包。源码与图形遵循 Apache-2.0，包含模型的固件遵循独立模型条款及依赖许可。

回滚前导出试用新增家庭数据，保留同一板卡的完整备份和兼容网关配置。重新启用旧网关后，才能通过 USB 切换 legacy 模式。
