# 验证与发布

[English](release.md) | **简体中文**

本实现已完成桌面静默验证，等待新架构的板上验收。项目版本保持 2.0.0，本轮不创建标签或重发已有资产。

## 当前验证

- C++ 配置、Live 客户端委派、两种 LLM、两种搜索、工具取消与持久化行为测试通过 ASan/UBSan。
- 61 项 Python 工具检查、4 项双眼预览检查、19 项训练规划检查通过。
- 100 次本机 TLS/CONNECT/语音与独立后端组合通过，包含证书、鉴权、限流和断连场景；全部使用假凭证。
- 8 小时等量合成 PCM 与 28,800 次后台工具循环加速完成，播放欠载为 0；桌面峰值约 3.11 MiB，预热后高水位增加约 160 KiB。不是板上内存测量或 8 小时墙钟运行。
- 干净源码目录成功构建 ESP32-S3：镜像 2,736,624 字节、静态 DIRAM 168,779 字节；安装器 dry-run 与 GitHub push/PR 检查通过，详见[脱敏记录](verification.json)。

本机网络驱动使用 Python SSL，HTTP 解析、服务适配与 Agent 使用真实 C++ 核心；ESP 的嵌套 mbedTLS 不能由桌面结果代替。默认检查不要求 TensorFlow。另在轻量训练环境运行 206 项 Python 训练用例：138 项通过、68 项需可选训练运行时或固定上游检出的用例跳过，无失败。

## 板上验收

设备连接后先备份并校验，再配置新格式并保持静音，测量 Live 与后台 HTTPS 并存时的内部堆低水位、最大连续块、队列峰值和断线恢复。资源失败、重复写入或旧音频复播不得通过。真人听感、AEC、装壳唤醒和日常家庭环境另行验收。

此轮未刷写设备，未改变现有家庭数据、音量或方向。主干合入以板上资源验收通过为条件，不能把先前版本的实机成绩记为当前架构成绩。

## 发布包

`tools/package-release.py` 依据已跟踪源码、匹配的模型策略和已构建镜像生成固件与模型包、许可文本、来源清单及 SHA256SUMS。禁止包含 NVS、配置、密钥、家庭数据和录音。检查包内脚本执行权限和文件校验，再单独确认发布；源码与模型条款分别保留。
